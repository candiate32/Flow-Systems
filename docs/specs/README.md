# Specs

One file per feature, written and agreed before the code: `NNN-short-name.md`.

Each spec says what the user sees, the data it touches, the edge cases, and the tests that prove it works. Keep it to a page.

1. `001-whatsapp-spike.md`: results of the provider spike (coexistence, send API, inbound and echo webhooks, fees).
2. `002-demo-slice.md`: Phase 1 demo for "Demo Interiors, Sarjapur Road" (form, `ingest-form`, acknowledgement, owner alert, admin list).
3. `003-modular-forms.md`: config-driven studio forms (themes, layouts, custom questions, gallery).
4. `004-production-engine.md`: Phase 2 engine v1 in slices A–F (jobs, follow-ups, webhook, metrics, operations, real provider).
